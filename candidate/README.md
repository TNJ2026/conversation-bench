# 五阶魔方（5×5×5）

纯浏览器原生实现的五阶魔方：CSS 3D 立体视图、打乱、导入、求解、重置。界面、魔方模型、局面校验、求解器和动画全部自行编写，没有第三方库、CDN、预编译求解器或现成查找表。

## 离线运行

直接用浏览器打开 `index.html` 即可（`file://` 即可运行，无需构建、无需后端、无需联网）。目录中的文件：

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构与样式 |
| `cube-core.js` | 模型、记号解析/格式化、局面校验、求解器（也可在 Node 中 `require`） |
| `app.js` | CSS 3D 渲染、视角拖动、逐层动画、按钮逻辑、`window.benchCube` |

## 操作

- **视角**：在立体视图上用鼠标或触摸拖动；方向键微调；双击恢复默认视角。视角只改变显示，不改变逻辑状态，也不写入转动记录。
- **打乱**：随机 36 步，保证同时包含外层与内层（如 `2R`、`3U`）转动，并逐步播放、记录。
- **导入**：输入 150 字符面片串后点“导入”。成功后该局面成为新的基准局面，转动记录清空。不合法或不可达的局面会在错误框中提示原因，当前状态与已有转动记录保持不变。“填入当前状态”可把当前面片串写入输入框。
- **求解**：先计算，再在立体视图中逐步播放每一步对应层的旋转，每转完一步才提交该步逻辑状态。计算或播放期间求解与打乱按钮禁用，重复点击被忽略。状态栏显示步数、计算耗时和播放耗时。
- **重置**：立即取消正在进行的计算和动画，恢复复原状态并清空记录；被取消任务的异步结果不会写入。
- **动画速度**：慢 / 中 / 快 / 极快。

## 面片串格式

长度 150，面序 `URFDLB`，每面 25 字符。每一面从外朝内看，按行从左上读到右下；四个侧面的上边邻接 U，U 的下边与 D 的上边邻接 F。字母表示固定颜色，每种 25 枚。可以导入整体旋转过的朝向（固定中心不在默认位置）。求解会先用整块转动（如 `5Rw`、`5Uw`）把固定中心转回 U/R/F/D/L/B，这些转动同样播放并记录。

## 转动记号

从指定面向内数层。无后缀为直视该面顺时针 90°，`'` 为逆时针，`2` 为半转。

- `R`：外层；`Rw`：第 1–2 层；`3Rw`…`5Rw`：从该面起 3–5 层（`5Rw` 即整体转动）
- `2R`…`4R`：单独的内层
- `2-3Rw`、`2-4Rw`：指定区间的内层一起转
- 其他面同理

`window.benchCube.getState()` 返回独立快照 `{facelets, animating, moveLog}`；`moveLog` 只含当前基准局面之后已完成的转动，记号如上。

## 局面校验

1. 长度、字符集、每色 25 枚。
2. 六个固定中心必须是标准配色的某个整体朝向（24 种之一），否则判为不可达。
3. 转到标准朝向后按块检查：
   - 角块：颜色组合存在、无镜像、无重复；朝向和 ≡ 0 (mod 3)。只扭转一个角块会在这里被拒绝。
   - 中棱：颜色组合存在、无重复；翻转数为偶数。只翻转一个中棱会在这里被拒绝。
   - 角块排列奇偶 = 中棱排列奇偶。只交换两个中棱（或两个角块）会在这里被拒绝。
   - 翼棱：每个位置按固定手性读取的有序颜色对必须对应 24 个翼棱之一且不重复。翼棱不能原地翻转，所以颠倒的翼棱会被拒绝。翼棱排列奇偶不受限制（最后一条棱的翼棱奇偶是合法的）。
   - 角中心、棱中心：每色各 4 枚（同色中心不可区分，无奇偶限制）。

## 求解算法

本求解器按块类型逐类归位，全部使用程序自己生成的纯 3-循环。思路与公开的归约法说明相同（先处理中心与棱的配对/奇偶，再处理三阶部分），但步骤是逐类直接归位，不是逐步套用公式。允许非最短解，一般为 500–650 步。

### 1. 自生成三循环表（运行时生成，约 0.3 s）

- **交换子搜索**：枚举交换子 `[A, B] = A B A' B'`，其中 A 为任意单层转动，B 为单层转动 `x` 或其共轭 `c x c'`。计算每个交换子对 150 个面片的置换并分类，保留满足以下条件的：
  - 恰好让某一类块中的 3 个块构成刚性 3-循环；
  - 不动任何“更早处理”的块类型（固定中心 < 角块 < 中棱 < 翼棱 < 角中心 < 棱中心），更晚的类型允许被打乱。

  原理：若 B 只把一个块送进 A 所在层，A 与 B 的作用范围只交于一个块，交换子就是 3-循环。例如 `[2U, R U R']` 循环 3 个翼棱，`[2R, U 2L' U']` 循环 3 个角中心。A 是内层时，交换子在“三阶骨架”（角块、中棱、固定中心）上的像为恒等，所以自动不影响角块和中棱。
- **共轭扩展**：对每个已知循环做 `m · C · m'`（m 为 45 种单层转动之一），用广度优先补全每类块所有可能的 (起点, 终点, 第三点) 面片三元组。三元组以面片为单位，所以同时决定块的位置与朝向。结果：角块 1008 个循环，中棱 1760 个，翼棱、角中心、棱中心各 4048 个。

### 2. 求解步骤

1. 整块转动，使固定中心归位。
2. 若角块排列为奇，转一次 `U`（角块与中棱的奇偶同时改变；校验保证两者一致）。
3. 角块、中棱：逐个位置查表，选一个“目标块所在面片 → 目标面片 → 任一未锁定块”的循环，并选最短的。原位但朝向错误的块，用两个三循环的组合成对修正。
4. 翼棱奇偶：若翼棱排列为奇（包括最后一条棱两枚翼棱互换的情况），转一次 `2R`。它只改变翼棱和中心，不动角块和中棱。然后用翼棱三循环逐个归位。
5. 角中心、棱中心：逐个位置归位。同色中心可互换，所以第三点可以是已锁定、但颜色恰好满足需要的位置，因此不存在中心奇偶问题。
6. 合并同轴相邻转动，消去抵消步，并把同量的相邻层合成宽层记号（如 `Rw`、`2-3Rw`）。最后用记号从起始局面独立重放复核，确认复原后才开始播放。

求解计算在主线程上分段让出执行权，所以界面在计算期间仍能响应；重置会递增任务编号，旧任务在下一次检查时中止并丢弃结果。

## 动画

98 个表面块各是一个带 6 个面的 CSS 3D 盒子，内侧面为黑色，转层时缝隙不会露空。每一步只给受影响层的块加上旋转矩阵，按时间插值到 90° 或 180°。转完后才把这一步的置换应用到逻辑状态、重新着色并复位变换。
